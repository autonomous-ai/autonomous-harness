How it works open
A made-up coding agent works in a made-up repo. Its context fills with messages and tool results. Each tool result secretly belongs to one task, or is junk (logs, lockfiles, test spam). That hidden label is the ground truth.

Over budget, Jev judges every tool result at once: the state is the current task plus the last few messages, and each result is one question, keep / trim / drop, up to 100 per call. Messages are never touched. If the window is still above the target, the keeps Jev was least sure about get squeezed.

Needle recall is the share of truly needed tokens that survived. The slim tower is a simple baseline for contrast: it folds the oldest half into one short summary. It is not a measurement of any real product.

The agent edits session.json: tasks, vocabulary, budget, trimTo, target, distraction.

Your own transcript: put a transcript file in the workspace and set "source" to its name. Jev judges every tool result in it and the plan is saved to compaction-plan.json. There is no ground truth then, so recall is not shown. It is an analysis. It changes no live session.
