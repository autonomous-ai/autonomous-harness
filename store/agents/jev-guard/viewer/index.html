      How it works
      
        
      
          Every edit in project/ becomes a diff. Jev reads the diff and answers many typed
          questions in one call: is it safe to carry on, is a secret leaked, are tests weakened, is it
          destructive, and how risky is each file. The chips, the gauge and the heat are those answers.

      
          When the agent is quiet, a demo stream of made-up edits keeps running. Some have a risk
          planted in them, so the pane can score Jev: caught, missed, false alarm. Hide the risks better
          and Jev struggles, because quiet changes look like harmless ones and Jev only reads the first
          part of a big diff.

      
          The repo, the diffs and the keys in the demo stream are fake. This is a demo of fast typed
          decisions. It is not a security tool and not security advice.
