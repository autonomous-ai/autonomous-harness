# Models

One model per file, directly under `src/`; outputs land in `../STEP/` (and `../STL/`, `../GLB/`,
`../3MF/` when a model declares meshes). Build a model by running it: `python src/part.py`.

| Model | What it is |
|---|---|
| `part.py` | the starter: a 40 × 30 × 10 mm plate with a Ø6 mm hole, replaced by the first real part |
