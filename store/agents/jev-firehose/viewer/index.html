How it works
A seeded generator writes made-up inbox messages. Each one has a true team, so the pane can score Jev live. Jev reads a message once and answers five questions in one call: team, urgency, spam, needs_human, mood. A tile crosses the gate at the height of Jev's confidence. Under the threshold it drops to the amber lane for a big model. A red ring marks a wrong bin.

The chat agent designs the desk in firehose.json: teams, descriptions, phrases, noise, threshold.
