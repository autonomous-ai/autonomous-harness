How it works
These are your own messages, read from a file in the workspace. Jev reads each one once and answers five questions in one call: team, urgency, spam, needs_human, mood. A tile crosses the gate at the height of Jev's confidence. Under the threshold it drops to the amber lane for a big model or a person. There is no answer key here, so nothing is scored right or wrong.

Results go to triage.csv in the workspace, one line per message. Move the threshold and the file is rewritten. With a key, only the text column is sent to Jev. Without one, nothing leaves this machine.
A seeded generator writes made-up inbox messages. Each one has a true team, so the pane can score Jev live.
