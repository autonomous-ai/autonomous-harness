    How it works
    On every key, the palette and the query are written out as text and Jev answers three typed questions in one call: which target to launch (a probability for every target), which group the person is after, and whether the query is clear enough to launch.

    When nobody types for 15 seconds a ghost typist, tagged DEMO, takes over. It picks a target it wants, types one of its names and launches Jev's first row, so the score is honest. Short queries, typos and look-alike targets make it harder for a real reason: the text Jev reads is less clear. The palette is made up and nothing is ever launched. Edit launcher.json to change the targets.
