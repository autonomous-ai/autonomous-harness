Reading the simulation

Wire colour is voltage: green is positive, grey is 0 V, red is negative.
Moving yellow dots are current; faster dots, more current.
ScopesThe strip along the bottom plots the watched parts over time. Its gear sets the scale.
NodesThe row above the circuit reads every labeled node's voltage, live.

Inspect

HoverPoint at any part: its current, voltage drop and power show in the bottom-right corner.
ClickFlip a switch or a logic input.
SlidersThe knobs in the right-hand column change a value while it runs.
Double-clickEdit a part's values.

Move around

ScrollZoom.
⌥ dragPan (or drag with the right button).
SpacePause or run, when the bar has focus.

Your changes

What you change here is yours to try; it is not saved to the file. Ask the agent to keep it. Revert loads the file again, and every save the agent makes replaces the circuit.
