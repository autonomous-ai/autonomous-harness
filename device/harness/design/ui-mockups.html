Interns Commander — Device UI (current state)

Round 466×466 AMOLED. This is a faithful reference of the UI as it ships today — every stage, drawn with the real colors, fonts, sizes and layout pulled from device/harness/main/ui/ui_screens.c. It is the starting point for the design team to polish; nothing here is a proposal yet.

Each frame is authored at true 466px and scaled to 300px for display, so proportions are exact. The status bar (top) and page dots (bottom) are persistent overlays shown on in-session screens. Fonts are approximated in the browser (device uses Arial Unicode for Vietnamese + Montserrat for titles/icons); icons are SVG approximations of the LVGL symbol glyphs.

Notes for the design team

What's new since the old say/act/ask stream — the recap headline (the one-line summary on the project tile) and the todo checklist (green done / orange in-progress / grey-ring pending), plus a live token counter in the processing row. All three already render on-device.

Live event kinds today: processing (working row + tokens + todos), summary (recap tile card), done, error. The say / act / ask styles still exist but are only seen when replaying history after a restart.

Known gap worth a design call: after a device restart, the history-restore path drops the recap and todos — restored cards fall back to plain text and no checklist is rebuilt. Consider how a restored project should look.

Font constraint: the Vietnamese font only covers Latin + Vietnamese + a few glyphs (› ✓ ✗). All agent text is UTF-8-filtered to that set, so emoji / CJK are stripped on-device — mockups should avoid relying on them.
