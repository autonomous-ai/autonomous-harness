Notes for design. The screen is a true circle — keep content inside the inscribed square (~330px) and centred. Text renders in an Arial-metric font (the on-device Vietnamese font). Settings-row + picker glyphs are drawn here as SVG in the real device colours (device uses Figma ARGB icons of the same shapes — blue #367FFF mark on a navy #131a2a tile; brightness has no tile). The per-agent Model/Effort chips + pickers and the Wifi picker's big-hit-zone delete render on remote harnesses. Carousel order is agent0 → … → Harness → Settings; the battery cluster shows on Settings only. Passcode is a deliberately flat pattern lock (grey→green dots, green line). Wake is a single tap that fades in. Values are v0.1.79.
